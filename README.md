## 과제 구성

총 2개의 모듈로 구성되며, 각 모듈은 3시간 분량입니다.

- **Module A**  
  사진촬영 부스(Photo Booth) 서비스 이용을 위한 프론트엔드 화면을 구현하는 과제로,  
  사용자 인터페이스(UI) 구성 및 레이아웃 설계, 인터랙션 요소 구현을 중심으로 평가됩니다.

- **Module B**  
  공연 티켓 예약 시스템의 백엔드 기능을 구현하는 과제로,  
  데이터 처리 및 예약 로직 설계, 서버 측 기능 구현을 중심으로 평가됩니다.
